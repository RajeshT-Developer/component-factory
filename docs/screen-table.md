# Screen table integration

This batch connects the configuration foundation to the builder and HTML/React/Vue
exports. Existing consumer snapshots are not regenerated by this commit.

Choose Screen builder > Content type > Table. Edit columns/actions and sample-row
JSON, then choose Apply table changes. Unapplied drafts are not saved. When a
column key changes, update matching row fields. Use [] to preview the empty state.
Content text is still required for compatibility, including in table mode.
Old projects without table fields continue to render text.

HTML exports include sample rows. Listen for table-row-action on document; its
event.detail is { action, row }. React/Vue components omit sample rows and default
to an empty array: pass rows from the consuming application. React accepts
onRowAction(action, row); Vue emits row-action(action, row). Existing primary and
dropdown integrations remain. Keep ConfiguredTable and screen.css with all other
exported files when replacing a consumer's generated directory.

Rows need unique non-empty string ids and scalar configured cells. Invalid runtime
rows throw a descriptive error. Cells render as text. Native table headers,
caption, buttons and a keyboard-focusable scroll region are included. Row callbacks
only notify the host; API/business operations are not implemented.

Verification:

    node --test tests/unit/table-config.test.mjs tests/unit/table-source.test.mjs
    npm --prefix apps/workbench run build

Then manually verify builder table/empty previews, row actions, mobile width,
reload and project save/open. Export each framework, replace its consumer generated
files, pass rows, and build the consumer. These integration/build checks must pass
before merging; source/runtime unit tests alone do not establish browser parity.
The existing component parity suite remains separate and unchanged.

Deferred: API integration, sorting, filtering, pagination, virtualization and
multi-screen navigation-anchor namespacing. Table authoring drafts are limited to
1 MB to leave room under the existing project-file import size limit.
